# Plan: 安装 ES IK 中文分词插件

## 问题
ES 8.17.0 容器内无法访问 GitHub 下载 IK 插件，导致 `ik_smart`/`ik_max_word` 分析器不可用，后端启动失败。

## 方案
使用 `get.infini.cloud` 镜像下载 IK 插件，在 ES 启动时自动安装。

## 修改文件
1. `docker-compose.yml` — ES 服务添加启动命令安装 IK
2. `docker/es/install-ik.sh` — 安装脚本（已创建，需更新）

## 步骤
1. 修改 `install-ik.sh` 使用 `get.infini.cloud` 镜像 URL
2. 修改 `docker-compose.yml` ES 服务挂载脚本并执行
3. 重启 ES 容器
4. 验证 IK 插件安装成功
5. 重启后端验证 ES 连接正常

## 验证
- `docker exec tea-mall-es /usr/share/elasticsearch/bin/elasticsearch-plugin list | grep ik`
- 后端启动无 `mapper_parsing_exception` 错误
